# EIE3320 Group Project

Java object-oriented graphics program for EIE3320 Lab 2. It calculates the
area and perimeter of circles, squares, and rectangles, stores mixed shapes
in a `Picture`, and draws shapes with the supplied BlueJ `Canvas`.

## Run in BlueJ

Open this folder as a BlueJ project and compile all classes. Right-click
`PictureTester` or `ShapeTester` and run `main(String[] args)` with `{}`.

`PictureTester` runs the six-shape example from the lab sheet. In
`ShapeTester`, choose `c`, `s`, or `r`, enter positive decimal dimensions,
and use `x` to exit.

## Run from a terminal

```text
javac *.java
java PictureTester
java ShapeTester
```

The source headers still contain student name and ID placeholders. Complete
these before course submission.
